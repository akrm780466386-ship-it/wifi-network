# WiFi Network Management System

واجهة عربية أولية لبوابة شبكة واي فاي، بتصميم متجاوب واتجاه RTL.

## الملفات
- `index.html`: صفحة البوابة، عرض الباقات، نموذج دخول المشترك، ومعاينة لوحة الإدارة.

## التشغيل
افتح `index.html` في المتصفح، أو انشر المستودع كـ GitHub Pages / خدمة Static Site.

## الحالة الحالية
هذه نسخة Front-end تجريبية فقط:
- نموذج الدخول لا يتحقق من بيانات البطاقات ولا يتصل بـ MikroTik.
- الباقات المعروضة تجريبية/عناصر توضيحية وليست أسعاراً فعلية.
- لوحة الإدارة للمعاينة فقط وليست محمية ولا تحفظ بيانات حقيقية.

## الخطوات القادمة
ربط قاعدة بيانات ومصادقة آمنة، ثم تكامل MikroTik لإدارة المستخدمين والبطاقات والجلسات، وإضافة صلاحيات مدير وتقارير فعلية.
