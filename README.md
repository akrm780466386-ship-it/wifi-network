# شبكة واي فاي

بوابة عربية تجريبية لكروت الاتصال بتصميم داكن أزرق وواجهة RTL.

## الصفحات
- `index.html`: بوابة المشتركين وإدخال رمز الكرت وعرض جلسة تجريبية.
- `admin.html`: لوحة إدارة الكروت التجريبية.

## رموز جاهزة للتجربة
- `WIFI100`: كرت يومي تجريبي، 1 GB.
- `WIFI200`: كرت أسبوعي تجريبي، 5 GB.
- `WIFI500`: كرت شهري تجريبي، 20 GB.

## وظائف النسخة التجريبية
- قبول رموز الكروت التجريبية وإظهار جلسة بوقت وبيانات افتراضية.
- إنشاء كروت جديدة من صفحة الإدارة.
- إيقاف الكرت أو إعادة تفعيله.
- عرض إحصائيات تجريبية ونسخ رمز الكرت.
- حفظ بيانات المحاكاة في localStorage داخل المتصفح.

## حدود مهمة
هذه نسخة Front-end تجريبية فقط. لا تتصل براوتر أو جهاز Reader أو MikroTik أو RADIUS، ولا تمنح اتصال إنترنت فعليًا. الوقت والبيانات والجلسات محاكاة وليست قياسات حقيقية. بيانات localStorage محلية لكل متصفح وجهاز، وليست قاعدة بيانات مشتركة أو آمنة للإدارة الحقيقية. صفحة الإدارة غير محمية بتسجيل دخول، لذلك لا تضع فيها بيانات حقيقية أو حساسة.

## الانتقال إلى التشغيل الحقيقي لاحقًا
يتطلب معرفة جهاز/نظام إدارة الشبكة وطريقة التكامل الرسمية، ثم بناء Backend آمن ومصادقة إدارية وصلاحيات وقاعدة بيانات وربط الراوتر/القارئ.
