# شبكة واي فاي

بوابة عربية متجاوبة لإدخال كود كرت الاتصال، بتصميم أسود وأزرق وبواجهة RTL.

## الملفات
- `index.html`: بوابة المشتركين، عرض كروت الاتصال، وإدخال كود الكرت.
- `admin.html`: معاينة تصميم لوحة الإدارة.

## التشغيل
افتح `index.html` في المتصفح أو انشر المستودع كـ Static Site.

## الحالة الحالية
هذه نسخة Front-end فقط:
- واجهة إدخال كود كرت ZaiFi جاهزة بصريًا، لكن لا تتحقق من الكود ولا تمنح الإنترنت.
- صفحة الإدارة تصميمية فقط، وليست محمية أو متصلة ببيانات حقيقية.
- لا توجد أسعار أو مدد فعلية مضافة؛ تفاصيل الكروت تُحدد من نظام الشبكة.
- لا يتم تخزين كود الكرت أو إرساله لأي جهة من هذه النسخة.

## المطلوب لإكمال الربط التشغيلي
1. تحديد نوع القارئ/وحدة إدارة الشبكة المقصودة باسم Reader، وتوفير اسم المنتج أو صفحة إعداداته/وثائقه.
2. معرفة الراوتر أو وحدة التحكم التي تدير الـ Wi-Fi وCaptive Portal.
3. الحصول على طريقة التكامل الرسمية (API أو RADIUS أو إعدادات بوابة الدخول) وصلاحيات محدودة وآمنة.
4. بناء Backend للتحقق من كود الكرت، قراءة حالة الجلسة والمدة والاستهلاك، وتوفير لوحة إدارة بمصادقة وصلاحيات حقيقية.

**مهم:** استضافة الموقع وحدها لا تستطيع معرفة الأجهزة المتصلة بالواي فاي أو السماح لها بالإنترنت؛ هذا يتطلب تكاملًا مع الراوتر/وحدة التحكم الفعلية.
